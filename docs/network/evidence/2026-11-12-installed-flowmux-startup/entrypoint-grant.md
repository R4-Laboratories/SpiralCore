Trial 8 used the same signed workload package and resource limits as [trial 7](activation-only.md). A fresh issuer explicitly granted `activate-environment` and `run-entrypoint` in the signed plan. The controller now invokes the workload through the original authenticated guest control session. Startup returned an error before that invocation. The cooperating peer accepted zero callers, and the archived workload audit file was empty. [Measured results and original digests](entrypoint-grant.json)

The controller retained the startup cause internally and returned the generic installed-startup error. The guest console shows Linux kernel startup. The original guest state directory, inspected before namespace teardown and again on the retained ext4 image, lacked both `plan.json` and `verb-grant.json`. The selected runtime requires the signed, guest-specific grant before it opens the authenticated activation channel. Source review found that the transient selected SDK path populated the launch configuration but did not perform the canonical grant persistence used by other admitted entrypoint paths. The missing grant is a demonstrated prerequisite. The generic error did not expose the first failing instruction.

Original SDK retirement and tenant stop succeeded. The final snapshot contained zero guests and workers. Its recorded host metadata, cache, and staging debts matched trial 7 in size. The controller could not verify the four original reservation identities because startup returned before the guest observation. The SDK command and its collected children used 30.66 s user and 1.40 s system CPU over 33.22 s wall time, with a reported virtual peak of 637,424 KiB and resident peak of 273,864 KiB. These times cover startup and retirement. The guest delivered no workload terminal event or application readback.

The preceding Linux component tests passed one signed-grant test, one lost-parent-authority test and six original socket and child tests. The nested protocol-peer subprocess served as a fixture. Two real registered endpoint tests failed in an extended temporary path that needed a separate socket directory. The same binary passed both tests in the ordinary short path. The actual guest trial used a fresh short path. The next native gate requires the original signer’s guest-specific verb grant to reach activation under the original admission.
