It requires Active and the originally acquired generation, so a newer valid record cannot be silently adopted. Its original SH remains held throughout validation and duplication; a legitimate owner cannot obtain holders EX to publish another state concurrently. It does not reopen a pathname for the exported lease, explicitly unlock, publish state, reset generation or consume the original guard. Errors after a partial clone drop only temporary duplicates; the original guard remains alive. Successful ownership moves into non-Clone `HolderHandoff`, preserving SH until the final duplicated holder description closes. The fixed176-byte length and SHA-256 cover the complete re-encoded canonical record; decoding rejects every noncanonical/reserved/checksum difference, so the re-encoding is byte-identical to the verified record. The digest is an exact-state comparison, not authentication or a credential.
