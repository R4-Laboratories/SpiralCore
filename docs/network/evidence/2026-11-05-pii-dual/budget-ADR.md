## Placement and lower bound

N means mapped endpoint CHILD PROCESSES on ONE installed host in ONE real tenant, one local flow per child. A remote host/reference peer is never charged here. A two-host WAN with one guest on each host uses N=1 independently; it does not prove same-host N=2 capacity.

The actual InstalledScopeController::prepare constructs BOTH a local ObjectSender and ObjectEndpoint, and Duplex::spawn consumes both. ResourceProfile::SmallV1.operation_charge() therefore charges one LOCAL sender+receiver8,349,628B once per local connection. This is not a client/server reference-peer pair. TlsCarrier::connect constructs one local TLS connection; the12MiB derivation covers that client's OR server's local state, not both hosts. Two endpoint children each making one connection therefore need two local codec pairs and two TLS terms. A reference peer outside the shipping service is excluded.
