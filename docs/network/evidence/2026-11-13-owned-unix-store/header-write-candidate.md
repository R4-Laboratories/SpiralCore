# Windows ordered-stream results with a combined publication header

The Server 2025 timing build still failed at the two-second operation deadline. The Server 2025 and Server 2022 stall builds each acknowledged and verified all 4,096 blocks in both directions. All three used the candidate writer, which submits a 49- or 81-byte header to one `write_all` call before writing the payload and syncing the file. Each test ran both endpoints in one process on a hosted Windows runner, with the original 240-second workload deadline and 64-publication retention limit. **Failed Commit.** The right sender recorded one reply-channel timeout while waiting for the Commit reply for block 1,439. The left reader timed out waiting for that block. At the concurrent snapshot, the left receiver had completed 1,440 Commit-handler spans and 1,439 Commit-reply send spans. Those handler spans totaled 34.4953091 seconds, with a maximum of 0.8878051 seconds. The right receiver’s maximum was 1.4915375 seconds. The aggregates carry no ordinal for either maximum. The two-second send deadline covers Begin, Data and Commit together. These observations locate the expired wait but leave its underlying cause unresolved. [Server 2025 timing job](https://github.com/R4-Laboratories/SpiralCore/actions/runs/43500008589/job/132142992756)

**Completed transfers.** Each passing run read back 67,108,864 application bytes per direction and retained 64 publications per endpoint. Final TLS counts were 5,395,050 bytes left-to-right and 5,395,015 bytes right-to-left. The Server 2025 sampler retained six observations with a worker inside the Commit endpoint handler at ordinals 245, 249 and 271. Four samples at ordinal 271 spanned 331 ms with unchanged TLS counters and reported process CPU. That transfer subsequently completed. Server 2022 retained zero stall samples. [Server 2025 stall job](https://github.com/R4-Laboratories/SpiralCore/actions/runs/43500008589/job/132142992795) · [Server 2022 stall job](https://github.com/R4-Laboratories/SpiralCore/actions/runs/43500008589/job/132142992748)

With the original writer, the Server 2025 timing build timed out after 230 verified blocks per direction. Its stall build completed in 152.687079 seconds of lifecycle wall time and 72.968750 seconds of process CPU. These are individual executions on separate hosted jobs. They establish that the timeout persists with the candidate; they leave the header change’s performance effect undetermined. [Original-header baseline](header-write-baseline.md)

The tested merge and candidate PR head have the same Git tree. The executable size and SHA-256 matched before and after each run. The three ZIP digests and all 17 listed member hashes matched the artifact receipts. Per-job executable hashes, source identity, setup costs, directional TLS counters and Commit timing aggregates are recorded alongside the results.
