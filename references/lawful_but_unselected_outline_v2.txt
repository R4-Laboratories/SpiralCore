LAWFUL BUT UNSELECTED
Outline Toward a Configuration-Space Account of Realized Objects,
Reachability, Fixed Components, and Unselected Alternatives

Working outline for later formalization — Version 2
Author: Matt
Status: Conceptual / pre-formal draft


0. PURPOSE OF THIS REVISION

This revision keeps the original core distinction:

    lawful != reachable != realized

but adds a second, stronger engineering question:

    What changes when the necessary component set is already known,
    and the primary unknown is how those components must be arranged?

The paper is still not intended to prove a complete metaphysical system.

Its narrower goals are:

1. State the object-as-configuration intuition clearly.
2. Distinguish components from arrangement.
3. Separate lawfulness, reachability, realization, and functional success.
4. Examine what remains lawful but unselected after one configuration is realized.
5. Introduce the "known components / unknown arrangement" design problem.
6. Explain why this matters for SpiralCore-like deterministic systems.
7. Relate the proposal to Aristotle, process philosophy, structural realism,
   and modal metaphysics without collapsing them into one doctrine.
8. Identify what must be formalized before stronger ontological claims are made.

The strongest metaphysical claim — "everything already exists" — remains open.

The formal program can proceed using the weaker claim:

    A constrained system may admit a space of lawful configurations larger
    than the single configuration actually realized.

2. CENTRAL THESIS

A realized object is not merely an inventory of components.

It is a stabilized organization of components under constraints.

Therefore:

    components alone do not determine the realized object;
    relations among components matter;
    the same component inventory may admit multiple lawful arrangements;
    only some lawful arrangements may be reachable;
    only some reachable arrangements may perform the target operation;
    only one or a few may actually be realized.

The paper therefore distinguishes at least four categories:

LAWFUL
    A configuration satisfies the governing constraints of the model.

REACHABLE
    A lawful configuration can be reached from the present state using the
    permitted dynamics and available resources.

FUNCTIONAL
    A reachable or lawful configuration performs the target operation.

REALIZED
    A configuration is actually instantiated.

These are not identical.

A configuration can be:

    lawful but unreachable;
    reachable but nonfunctional;
    functional but unrealized;
    realized without exhausting the other lawful possibilities.


3. THE MINIMAL ANALOGY: THE TORNADO

3.1 The tornado is the object

A tornado is not identical to:

    - the storm system,
    - the Earth beneath it,
    - any one parcel of air,
    - heat,
    - pressure,
    - wind,
    - moisture,
    - shear.

Those are components, conditions, and relations.

The tornado is the physically realized organized configuration that emerges
when those ingredients enter a sufficiently specific regime.

A simplified ladder is:

    components
        -> constrained relations
        -> organized flow
        -> temporary stabilization
        -> tornado

The tornado is physically real even though:

    - its constituent air is continuously changing,
    - its shape changes,
    - it moves,
    - it strengthens and weakens,
    - it retains degrees of freedom,
    - it can dissipate while its components remain.

This supports a central identity claim:

    The object is not reducible to any one component.
    The object's identity is carried by an organized relation among components.


3.2 The television is the same kind of problem at a different stability regime

A television is more rigid and intentionally engineered, but the same conceptual
distinction applies:

    silicon + metals + glass + polymers + charge + fields + geometry
        -> constrained organization
        -> characteristic operation
        -> television

The television is not identical to:

    - silicon,
    - copper,
    - glass,
    - plastic,
    - electrons,
    - electromagnetic fields.

Those are components.

The television is the organized physical configuration that makes those
components behave as a television.

Therefore the tornado / television comparison is not:

    natural process vs real object

but more usefully:

    dynamically stabilized configuration
    vs
    mechanically stabilized configuration.

Both can cease to exist as that object while their components continue to exist.


4. THE ENGINEERING INVERSION: START WITH THE COMPONENT SET

Ordinary engineering questions are often framed as:

    "What components do I need to build device X?"

The present proposal asks the inverse problem:

    "Suppose I already know the necessary component set.
     What arrangement of those components makes X possible?"

This is a materially different design problem.

Let the known component set be:

    C = {c1, c2, ..., cn}

The uncertainty is no longer primarily in C.

The uncertainty is in the relational structure imposed over C:

    G = (C, R)

where R may encode:

    - adjacency,
    - geometry,
    - orientation,
    - phase,
    - timing,
    - coupling strength,
    - boundary conditions,
    - directionality,
    - ordering,
    - allowed transformations.

Most possible R are expected to be useless.

Some may be unlawful.
Some may be lawful but unreachable.
Some may be lawful and reachable but fail the target operation.
Some may perform neighboring operations.
A small subset may realize the desired device.

This reframes engineering as:

    fixed components
        -> constrained arrangement space
        -> lawful arrangements
        -> reachable arrangements
        -> functional arrangements
        -> realized configuration


5. NECESSARY COMPONENTS ARE NOT SUFFICIENT ARRANGEMENT

This distinction is critical.

Knowing that a component is necessary does not tell us how to arrange it.

If every successful realization of operation O requires components C,
then C may be necessary.

But:

    necessary component set
        !=
    sufficient device description

A correct bill of materials may still leave the main problem unsolved.

The missing information can reside in:

    - topology,
    - geometry,
    - order,
    - timing,
    - phase,
    - coupling,
    - feedback,
    - boundary conditions.

This supports a sharper design principle:

    The function may be hidden less in the inventory of parts
    than in the lawful relations among them.


6. THE COMPLETE-COMPONENT-SET QUESTION

A stronger version of the engineering inversion is:

    What if the component set is not merely sufficient in practice,
    but known to be complete for the target operation?

This is a much harder claim and must be treated carefully.

To use "complete" rigorously, the paper must eventually define whether it means:

A. NECESSARY COMPLETENESS
    Every component required by any successful realization is already present.

B. MINIMAL COMPLETENESS
    No component can be removed without destroying the target operation.

C. FUNCTIONAL COMPLETENESS
    At least one arrangement of the present components can realize the operation.

D. MODEL COMPLETENESS
    The model contains every component class needed to represent the operation.

These are different.

The research problem becomes especially sharp if C is fixed:

    Given fixed C, find R such that (C, R) realizes operation O.

This is a configuration-search problem rather than a component-discovery problem.


7. ARRANGEMENT SPACE

Let:

    A(C)

be the space of possible arrangements over component set C.

Then define:

    L(C) subset of A(C)
        lawful arrangements

    R_s(C) subset of L(C)
        arrangements reachable from current state s

    F_O(C) subset of L(C)
        arrangements that realize target operation O

A realized device is then:

    a* in R_s(C) intersect F_O(C)

The unselected lawful arrangements are:

    U_L = L(C) \ {a*}

The unselected reachable arrangements are:

    U_R = R_s(C) \ {a*}

The unselected functional arrangements are:

    U_F = F_O(C) \ {a*}

This produces three different meanings of "other valid configuration":

    lawful alternative,
    reachable alternative,
    functionally equivalent alternative.


8. EQUIVALENCE CLASSES OF FUNCTIONAL ARRANGEMENTS

Two different arrangements may realize the same operation.

Define an equivalence relation:

    a_i ~_O a_j

if arrangements a_i and a_j are operationally equivalent under a specified
criterion.

Then:

    [a]_O

is the equivalence class of arrangements that realize operation O.

This immediately creates new research questions:

1. Is the target operation realized by one unique arrangement or many?
2. If many, what invariants are shared across the successful class?
3. Which parts of the arrangement are essential?
4. Which parts are implementation detail?
5. Can two different substrates belong to the same operational equivalence class?

This is one direct route from the philosophy to physical realization.


9. DEGREES OF FREEDOM

A realized object does not usually determine every variable completely.

A tornado can vary in:

    - position,
    - orientation,
    - radius,
    - internal velocity field,
    - pressure distribution,
    - intensity,
    - direction,
    - shape.

The object therefore retains unresolved degrees of freedom while remaining
within the same broader identity class.

This motivates:

    object identity
        !=
    one exact microscopic state.

The paper must eventually define:

    Which variations preserve identity?
    Which variations create a new object?
    Which variations destroy the object?
    Which variations change only function?


10. LAWFUL, REACHABLE, FUNCTIONAL, REALIZED

The core distinctions can now be stated more carefully.

LAWFUL
    Allowed by the governing constraints.

REACHABLE
    Accessible from the present state.

FUNCTIONAL
    Performs the target operation.

REALIZED
    Actually instantiated.

A configuration can therefore be:

    lawful but unreachable;
    reachable but nonfunctional;
    functional but unreachable from the present state;
    functional and reachable but unselected;
    realized.

This is a richer hierarchy than the original three-way distinction.


11. THE HARD QUESTION: WHAT HAPPENS TO UNSELECTED CONFIGURATIONS?

Suppose a* is realized.

Selection does not imply:

    every other arrangement was unlawful.

Nor does it imply:

    every other arrangement remains reachable.

Once a* is realized:

    - resources may be consumed,
    - boundaries may move,
    - geometry may change,
    - symmetry may break,
    - couplings may change,
    - hysteresis may store history,
    - entropy may increase,
    - new states may become reachable,
    - old states may become unreachable.

Therefore distinguish:

    lawful before selection
    reachable before selection
    functional before selection
    realized
    lawful after selection
    reachable after selection
    functional after selection

The pre-selection and post-selection spaces need not match.


12. SIMPLE EXAMPLE: THE BALL ON A RIDGE

A ball sits on a ridge.

Before motion:

    left path  = lawful
    right path = lawful

The ball rolls left.

Then:

    realized = left

But:

    right was not therefore unlawful.

After the ball reaches the left valley:

    right may no longer be reachable without new energy.

Therefore:

    lawful does not mean reachable
    reachable does not mean functional
    functional does not mean realized
    unrealized does not mean unlawful


13. WHAT THE TORNADO / TV ANALOGY IS DOING WELL

A. OBJECT IDENTITY
    The object exists at the level of organized configuration.

B. TEMPORARY STABILITY
    Real objects need not be permanent.

C. COMPONENT REPLACEMENT
    Material may enter and leave while identity persists.

D. DEGREES OF FREEDOM
    The object can vary without immediately ceasing to be itself.

E. PATH DEPENDENCE
    History can affect present state.

F. DISSIPATION
    The object can cease while components remain.

G. MULTIPLE LAWFUL FUTURES
    One present state can admit multiple lawful next states.

H. SELECTION WITHOUT INVALIDATION
    One realized route does not invalidate every unselected route.

I. ARRANGEMENT OVER INVENTORY
    The same components can support radically different organizations.

J. STABILITY AS A DESIGN VARIABLE
    Tornado and television differ substantially in stabilization mechanism,
    not merely in "realness."


14. WHAT NEEDS MORE WORK

A. OBJECT IDENTITY CRITERION

What invariant makes "this tornado" the same tornado over time?

Candidates:

    - coherent flow continuity,
    - persistence of a circulation core,
    - spatiotemporal continuity,
    - causal continuity,
    - topological continuity,
    - a tolerance-bounded family of observables.

This must be operationalized, not assumed.


B. COMPONENT COMPLETENESS

How can we know that C is complete?

A strong "known-complete component set" claim requires evidence.

The paper should separate:

    known necessary components
    suspected sufficient components
    demonstrated sufficient component set
    minimal sufficient component set


C. ARRANGEMENT SPACE EXPLOSION

Even with fixed C, A(C) may be enormous.

Permutations alone grow combinatorially.

Adding:

    geometry,
    graph topology,
    phase,
    continuous parameters,
    orientation,
    timing,
    boundary conditions

can make the search space vastly larger.

Therefore a major engineering problem is:

    What invariants or constraints prune arrangement space lawfully?


D. MODEL RELATIVITY

A configuration space depends on:

    - chosen variables,
    - spatial scale,
    - temporal scale,
    - governing equations,
    - boundary conditions,
    - coarse-graining.

Therefore "lawful" must always be indexed to a model.


E. MATHEMATICALLY DESCRIBABLE VS PHYSICALLY LAWFUL

The paper must separate:

    conceivable
    mathematically representable
    model-consistent
    physically lawful
    dynamically reachable
    functionally successful
    realized


F. NONSELECTION AS INFORMATION

The paper should not yet claim:

    "Every unselected route leaves a physical trace."

Instead ask:

    Under what conditions does nonselection remain structurally
    or informationally relevant?

Candidate formal measures:

    - entropy reduction,
    - branch elimination,
    - reachable-set contraction,
    - mutual information,
    - reduction in feasible configuration volume,
    - graph-connectivity change.


G. SUBSTRATE DEPENDENCE

Some operations may depend essentially on specific physical substrates.

Therefore ask:

    Which invariants survive a substrate change?
    Which are substrate-bound?


15. ARISTOTLE: WHAT RELATES

15.1 Hylomorphism

Aristotle's hylomorphism treats physical objects as compounds of matter and form.

A cautious modern comparison is:

    matter ~= components/material
    form   ~= organization that makes the material one kind of thing

This is relevant to:

    silicon alone is not a television;
    organized silicon and other components can constitute one.

Useful inheritance:

    - matter alone does not explain object identity;
    - organization helps explain how parts constitute one thing;
    - generation need not mean creation ex nihilo.

The current proposal should not be described as simply Aristotle restated.


15.2 Potentiality and actuality

Aristotle's potentiality / actuality distinction is adjacent to:

    possible or lawful arrangement
        vs
    realized arrangement.

But:

    potentiality != modern reachable state
    actuality != the full present formalism

Aristotle provides historical precedent for separating:

    what a thing can be or do
    from
    what is presently actual.


15.3 Arrangement of incidents

A separate Aristotelian thread in Poetics treats mythos as the arrangement or
composition of incidents.

This is relevant at the structural level:

    explanatory force can depend on ordering and relations among elements,
    not merely on the inventory of elements.

This should not be overstated.

Poetics is not being treated as a hidden dynamical-systems text.

The useful parallel is:

    list of parts != organization of parts.


16. PROCESS PHILOSOPHY

Process philosophy emphasizes becoming, occurrence, and dynamic organization.

The tornado example overlaps naturally:

    a tornado is easier to understand as a persisting process-pattern
    than as a static lump of matter.

The present proposal can borrow the question:

    Is object persistence sometimes better modeled as continuity of organization
    through change rather than continuity of identical matter?

The paper does not need to claim that all reality is fundamentally process.


17. STRUCTURAL REALISM

Structural realism emphasizes the epistemic or ontological importance of relations
and structure.

This is adjacent to the present proposal because:

    the same operation may survive a change in implementation
    if the relevant structure is preserved.

This matters for SpiralCore if:

    a transformation can be realized in software,
    geometry,
    optical hardware,
    acoustic systems,
    magnetic systems,
    or another substrate.

However:

    resemblance is not enough.

A valid cross-substrate claim requires a mapping that specifies:

    - which objects correspond,
    - which relations correspond,
    - which invariants are preserved,
    - whether the mapping is exact, approximate, isomorphic, homomorphic, etc.


18. MODAL METAPHYSICS: ACTUALISM AND POSSIBILISM

The actualism / possibilism debate concerns the ontological status of nonactual
possibilities.

This is relevant to the stronger statement:

    "everything already exists."

The present paper does not need to settle that dispute.

A safer operational claim is:

    the model contains lawful but unrealized configurations.

That supports the engineering thesis without requiring that every unrealized
configuration independently "exists" in a metaphysical sense.

Separate:

ENGINEERING THESIS
    lawful alternatives are elements of a model/state space.

STRONG METAPHYSICAL THESIS
    nonactual lawful configurations possess ontological status beyond the model.

The first can be formalized without proving the second.

20. PROVISIONAL FORMAL SKELETON

Let:

    C          = fixed component set
    A(C)       = possible arrangement space
    L(a)       = predicate: arrangement a is lawful under model M
    R(a | s)   = predicate: arrangement a is reachable from state s
    F_O(a)     = predicate: arrangement a realizes operation O
    A*(t)      = actual realized arrangement at time t

Then:

    lawful set:
        L_C = {a in A(C) : L(a)}

    reachable set:
        R_s = {a in L_C : R(a | s)}

    functional set:
        F_O = {a in L_C : F_O(a)}

    candidate successful realizations:
        S_O(s) = R_s intersect F_O

    realized arrangement:
        a* in S_O(s)

    lawful but unselected:
        U_L = L_C \ {a*}

    reachable but unselected:
        U_R = R_s \ {a*}

    functional but unselected:
        U_F = S_O(s) \ {a*}


21. PRE- AND POST-SELECTION REACHABILITY

For a transition from state s0 to s1:

    R_pre  = R(s0)
    R_post = R(s1)

Define:

    lost reachability:
        D- = R_pre \ R_post

    newly reachable states:
        D+ = R_post \ R_pre

This gives a minimal formal language for:

    "What did the selection change?"

The same construction can be extended to functional sets.


22. INFORMATION IN NONSELECTION

The stronger question is not merely:

    "What path did not happen?"

It is:

    "What information is contained in the deformation of the feasible
     configuration space after selection?"

Candidate measures:

    - log-volume change in reachable configuration space,
    - entropy over reachable alternatives,
    - number of eliminated equivalence classes,
    - information gained by exclusion,
    - transition-graph connectivity change,
    - posterior probability shift.

The key conceptual move is:

    nonselection can matter when it changes what remains feasible,
    inferable, or distinguishable.


23. CONFIGURATION-FIRST ENGINEERING

The paper can now state a concrete engineering program:

STEP 1
    Freeze the component set C.

STEP 2
    Define the target operation O.

STEP 3
    Define admissible relations R.

STEP 4
    Generate or characterize A(C).

STEP 5
    Apply lawfulness constraints.

STEP 6
    Apply reachability constraints.

STEP 7
    Test functional success.

STEP 8
    Record both selected and unselected lawful routes.

STEP 9
    Extract invariants shared by successful arrangements.

STEP 10
    Attempt substrate transfer using those invariants.

This turns the philosophical claim into a search procedure.


24. DESIGN IMPLICATIONS FOR SPIRALCORE-LIKE SYSTEMS

A. PRESERVE LAWFUL NONSELECTION

Do not collapse:

    unselected = invalid

Record whether a route was:

    lawful,
    reachable,
    evaluated,
    rejected,
    selected,
    invalidated.


B. WITNESS / PROVENANCE

Preserve enough history to distinguish:

    "this path was impossible"

from:

    "this path was possible but not selected."


C. REPLAY

A prior lawful branch should be reproducible or reconstructable if the system
claims deterministic provenance.


D. INVERSION

Treat inversion as a controlled transformation over a defined configuration space.

Ask:

    Which invariants survive inversion?
    Which reachable sets change?
    Which previously unselected states become reachable?


E. BOUNDARY CONDITIONS

No classification is complete without the boundary conditions under which the
configuration is considered lawful.


F. MUTANT / POISON CONTROLS

Introduce deliberately broken constraints to demonstrate that the system can reject
configurations that should be unlawful.

This distinguishes:

    "the system selected this"

from:

    "the system had no ability to reject alternatives."


G. FIXED COMPONENT MODE

SpiralCore can eventually expose a design mode in which:

    the component inventory is frozen,
    only relations are allowed to vary,
    lawful arrangements are enumerated or sampled,
    functionally equivalent arrangements are grouped,
    unselected but lawful arrangements are preserved.


25. CLAIMS THE PAPER SHOULD NOT MAKE YET

Do not claim, without further work, that:

    - all imaginable things can be made;
    - every mathematically describable arrangement is physically lawful;
    - every lawful arrangement is physically reachable;
    - every lawful arrangement is functionally useful;
    - the component set is complete unless completeness is demonstrated;
    - every unselected state leaves a physical trace;
    - every operation is substrate-independent;
    - tornado and television are ontologically identical in every respect;
    - Aristotle already formulated this formalism;
    - visual resemblance establishes structural equivalence;
    - the present framework is historically unprecedented;
    - all nonactual configurations literally exist.

A. A realized object can be modeled as an organized configuration of components.

B. Object persistence need not require persistence of identical components.

C. A realized object can retain degrees of freedom.

D. A known component inventory does not determine a unique arrangement.

E. Necessary components do not constitute a sufficient device description.

30. REVISED ABSTRACT DRAFT

This paper develops a pre-formal account of realized objects as stabilized
configurations within constrained arrangement spaces. Using a tornado and a
television as minimal examples, it distinguishes material components from the
relations that organize those components into a coherent object or operation.
The framework separates four categories that are often collapsed: lawful
configurations, dynamically reachable configurations, functionally successful
configurations, and actually realized configurations. It then introduces a
configuration-first engineering problem: if the necessary component set for a
target device is already known, the primary unknown may be the lawful arrangement
of those components rather than the discovery of additional parts. Realization of
one arrangement does not imply that unselected alternatives were unlawful, and
history-dependent dynamics may alter which alternatives remain reachable after
selection. The paper relates this framework to Aristotelian hylomorphism and
potentiality, process philosophy, structural realism, and modal metaphysics while
remaining agnostic on the stronger claim that nonactual possibilities possess
independent ontological existence. The long-term goal is to formalize the account
using arrangement spaces, reachability, functional equivalence, invariance,
hysteresis, and information-theoretic tools, and to use it as a rationale for
deterministic systems that preserve the provenance of lawful but unselected routes.


31. REVISED SHORT THESIS

A realized object is not merely a collection of components but a stabilized
organization of them under constraints. If the necessary components are already
known, the remaining design problem may be to discover which lawful arrangement
of those components realizes the target operation. Because one realized
configuration does not exhaust the lawful arrangement space, a rigorous system
should distinguish what was impossible from what was lawful, reachable,
functional, and unselected.

33. FINAL NOTE FOR THE NEXT DRAFT

The strongest path is still to formalize the smallest defensible claim first.

Start with:

    A fixed component set can admit more than one arrangement.
    Only some arrangements are lawful.
    Only some lawful arrangements are reachable.
    Only some reachable arrangements perform the target operation.
    Only one or a few are realized.
    Realization does not make the other lawful arrangements unlawful.
    Selection can change what remains reachable.

Then ask the new design question:

    If the parts are already known, what relation among them makes the device?

That keeps the argument falsifiable while preserving the larger philosophical
question for later:

    What is the ontological status of the lawful arrangement space itself?
